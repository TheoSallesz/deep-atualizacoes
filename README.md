# Deep — atualizações

Versões publicadas da extensão **Deep** para Adobe After Effects.

O painel do Deep consulta o arquivo `atualizacao.json` da [última release](../../releases/latest) e, quando há versão nova, mostra o aviso **Atualizar / Depois** com o resumo das novidades.

Cada release contém:
- `Deep-x.y.z.zxp` — o pacote da extensão (assinado);
- `atualizacao.json` — versão, novidades e SHA-256 do pacote (o painel confere antes de instalar).
